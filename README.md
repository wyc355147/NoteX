# Note 𝗫

**一款以离线为主的本地笔记应用。**

写下、整理、找回——笔记默认保存在你自己的设备上。

---

## 简介

Note 𝗫 是一款轻量的本地笔记应用，重心放在书写本身：打开就能记，记完就存好，日常使用不需要登录，也不需要对着空白页等待同步。

它面向喜欢把东西留在手边的使用方式——随时速记、慢慢整理、按自己的节奏找回来。

## 功能

- **写笔记**：Markdown 编辑支持编辑与预览两种视图，常用格式（标题、加粗、列表、引用、代码块、表格、任务清单等）一键可用；输入时标点会自动成对补全。
- **整理**：用置顶、收藏、标签与排序视图把笔记分层管理；回收站里的内容可查看、可恢复，误删不至于不可挽回。
- **搜索**：跨笔记与邮件的即时搜索，并保留搜索历史。
- **数据统计**：查看笔记数、字数、标签数与使用天数，以及编辑活跃度、创建趋势和标签分布。
- **备份与恢复**：把笔记导出为加密备份文件，之后可以导入、合并或恢复到其他设备。
- **应用锁**：为应用设置独立密码，解锁界面内置数字键盘；离开一段时间后回到应用需要重新解锁。
- **隐私空间**：一个与主笔记相互独立的加密空间，拥有各自的密码与数据，适合放置不方便混在一起的记录。
- **深色模式**：浅色、深色与跟随系统三种模式，切换即时生效。
- **多端适配**：手机与平板分别排布，横竖屏都能正常使用。

## 适合谁

- 习惯随手记录、希望打开应用就能写的人；
- 想给笔记做分类管理，又不愿意在一堆菜单里找功能的人；
- 更愿意把内容保存在自己设备上，而不是放到云端账号里的人；
- 需要在同一台设备上分开保存不同用途记录的人。

如果你的使用方式高度依赖多设备实时协作或团队共享，Note 𝗫 目前并不针对这类场景设计。

## 下载与安装

Note 𝗫 通过本仓库的 **Releases（发行页面）** 分发，无需前往应用商店。

1. 打开本仓库的 Releases 页面；
2. 选择适合你设备的最新版本文件下载；
3. 按页面说明完成安装；
4. 首次启动按引导完成初始设置，即可开始书写。

## 数据与隐私

- 笔记、邮件与个人资料默认保存在本机，应用不要求注册账号。
- 本地数据以加密形式存储；应用锁与隐私空间的密码由你自行设置，请务必记住。
- 应用以离线使用为前提设计，日常记录不依赖网络连接。
- 更换设备或清除应用数据之前，建议先在「设置 → 数据」中导出备份；备份文件同样经过加密，请妥善保管。

## 常见问题

**必须联网才能用吗？**
不需要。日常记录、整理与查看都可以离线完成。

**会同步到云端吗？**
Note 𝗫 目前不提供云端同步，笔记保存在本地；换设备时请通过备份文件迁移。

**卸载应用会丢失数据吗？**
卸载应用或清除应用数据会移除本机保存的内容，操作前请先导出备份。

**忘记应用锁或隐私空间的密码怎么办？**
密码由你设置，应用不会保存明文，也无法代为找回；重置密码只能新增一套凭据，若需重置隐私空间则其中数据会一并清除。

**备份文件能在其他设备上使用吗？**
可以。在另一台设备上导入同一份备份文件即可恢复；请确认两台设备使用的版本能够互相兼容。
