## 这是什么

Note 𝗫 是一款面向个人的笔记应用，面向 Android 平台，当前以 Beta 版本通过 GitHub 发行页分发。

产品的取舍与能力会持续调整：这一版强调的方向，下一版可能被更合适的做法取代。因此本文件不承诺任何具体功能、交互或数据处理方式，只承诺一件事——**你的内容属于你**：应用会以清晰、可预期的方式对待你的记录，具体做法写在应用内的《用户协议》与《隐私协议》里，并随版本同步更新。

## 获取与更新

- **平台**：Android（APK，手动安装）
- **分发**：仅通过 [GitHub Releases](https://github.com/wyc355147/NoteX/releases)
- **升级**：下载新版安装包直接覆盖安装，已有数据不随之清除


安装前请确认来源为上述发行页。升级前导出一份备份，永远是稳妥的习惯。

## 能力概览

Note 𝗫 围绕五件事构造，具体形式会随版本变化：

- **记录**——把想法尽快写下来；
- **整理**——让条目在变多之后仍然找得到；
- **查找**——需要时能立刻翻出旧内容；
- **保护**——敏感内容与访问权限由你自己控制；
- **迁移**——数据能导出、能带走、能换设备。

各能力当前的具体形态、入口与限制，见应用内引导与[发行说明](https://github.com/wyc355147/NoteX/releases)。

## 数据与隐私

应用如何存放数据、是否访问网络、申请哪些权限，以应用内《用户协议》与《隐私协议》为唯一权威来源；协议更新时，应用内会给出提示。

以下两点不随版本变化：

- **密码无法找回**。访问凭据不会以可还原的形式保存，这是有意设计；请自行妥善保管。
- **备份文件由你负责保管**。应用只负责导出与导入，不代为保存任何副本。
