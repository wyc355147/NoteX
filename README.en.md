## Overview

Note 𝗫 is a lightweight local note-taking app that puts writing first: open it and start typing, and it is saved as you go. Day-to-day use needs no sign-in, and you never sit waiting on a sync spinner.

It is built for the way many people actually keep notes — jotting things down as they come, tidying up gradually, and finding them again on their own schedule.

## Features

- **Write**: Markdown editing with separate edit and preview views. Common formatting — headings, bold, lists, quotes, code blocks, tables, task lists and more — is one tap away, and paired punctuation completes itself as you type.
- **Organize**: Pin, favorite, tag and sort notes into a structure that fits you. Deleted notes go to the recycle bin, where they can be reviewed and restored.
- **Search**: Instant search across notes and mail, with recent search history kept.
- **Statistics**: See note count, word count, tags and days in use, along with editing activity, creation trends and tag distribution.
- **Backup & restore**: Export notes to an encrypted backup file, then import, merge or restore it — including onto another device.
- **App lock**: Protect the app with its own password, entered on a built-in numeric keypad. After a period away, the app asks for the password again.
- **Private space**: A separate encrypted space with its own password and its own data, for records you would rather keep apart from the rest.
- **Dark mode**: Light, dark, or follow the system — switched instantly.
- **Phone & tablet**: Layouts tuned separately for phones and tablets, working in both portrait and landscape.

## Who it is for

- People who jot things down often and want an app that lets them write immediately;
- People who organize notes by category but would rather not hunt through menus for common actions;
- People who prefer keeping content on their own device over putting it in a cloud account;
- People who need to keep records of different purposes apart on the same device.

If your workflow depends heavily on real-time collaboration across devices, or on sharing notes with a team, Note 𝗫 is not designed for that scenario today.

1. Open the Releases page of this repository;
2. Download the latest version that fits your device;
3. Follow the instructions on that page to install;

## Data & privacy

- Notes, mail and profile details are stored on your device by default; the app does not require an account.
- Local data is stored in encrypted form. The app lock and private-space passwords are set by you — please keep them safe.
- The app is designed around offline use; everyday note-taking does not depend on a network connection.
- Before switching devices or clearing app data, export a backup from **Settings → Data**. Backup files are encrypted as well, so store them somewhere safe.

## FAQ

**Do I need an internet connection to use it?**
No. Writing, organizing and reading notes all work offline.

**Does it sync to the cloud?**
Note 𝗫 does not currently offer cloud sync; notes live locally. To move to another device, use a backup file.

**Will uninstalling the app delete my notes?**
Uninstalling the app or clearing its data removes what is stored on the device. Export a backup first.

**I forgot my app lock or private-space password.**
Passwords are set by you, and the app does not store them in plain form, so it cannot recover them for you. Resetting the password can only add a new credential; resetting the private space also erases the data inside it.

**Can a backup file be used on another device?**
Yes — import the same backup file on the other device to restore. Make sure the versions on both devices are compatible with each other.
