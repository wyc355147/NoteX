## What this is

Note 𝗫 is a personal note-taking app for Android, currently distributed as a Beta through its GitHub release page.

The product's trade-offs change as it matures: what one version emphasises may be replaced by a better approach in the next. So this file deliberately promises no specific features, interactions or data practices. It promises one thing instead — **your content belongs to you**: the app treats your records in a clear, predictable way. The exact practices live in the in-app *Terms of Service* and *Privacy Policy*, which are updated alongside each release.

## Get it and keep it updated

- **Platform**: Android (APK, sideloaded)
- **Distribution**: [GitHub Releases](https://github.com/wyc355147/NoteX/releases) 
- **Upgrades**: install the new APK over the old one; existing data is preserved


Please confirm the source is the release page above before installing. Exporting a backup before upgrading is always a good habit.

## What it does, broadly

Note 𝗫 is built around five concerns; their concrete form changes between versions:

- **Capture** — get a thought down before it escapes;
- **Organise** — keep entries findable as they pile up;
- **Retrieve** — pull old material back when you need it;
- **Protect** — keep sensitive content and access under your control;
- **Move** — export, carry away, and switch devices.

For how each of these looks today — entries, limits, entry points — see the in-app onboarding and the [release notes](https://github.com/wyc355147/NoteX/releases).

## Data and privacy

How the app stores data, whether it uses the network, and which permissions it requests: the in-app *Terms of Service* and *Privacy Policy* are the single authoritative source. When they change, the app tells you in-app.

Two things do not change between versions:

- **Passwords cannot be recovered.** Access credentials are never stored in a recoverable form. This is intentional — please keep them safe.
- **Backup files are yours to keep.** The app exports and imports them; it never stores a copy on your behalf.
